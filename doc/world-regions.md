# 四区域空间蓝图

## 总体空间关系

四章不是四次返回同一入口，而是同一流域上的连续上溯：`低地密林 → 淹没盆地 → 雾中山脊 → 水源圣所`。章节切换仍以单世界加载控制性能，但出生构图、地图方位和出口叙事必须保持空间连续。

## 01 低地密林

- 高度：约 `8.4 m → 0 m` 缓慢下行。
- 可视距离：`30–40 m`。
- 地表：连续湿泥路、陡近岸、倒木和板根。
- 植被：三层封闭林冠、高阔叶和藤本占主导。
- 水体：窄溪、终点瀑布和深潭。
- 记忆画面：密林尽头第一次看见横向水门。
- 出口：瀑布侧面的旧维护径进入下游漫滩背面。

## 02 淹没盆地

- 高度：整体起伏收窄为第一章约 `55–70%`，路线处于断续低堤。
- 可视距离：`55–70 m`。
- 地表：浅水、湿泥、半沉石板和淤积岛。
- 植被：莎草、蕨、稀疏棕榈、淹死树桩；降低连续树墙和高阔叶密度。
- 水体：`6–8` 片不规则浅水，深 `0.12–0.55 m`，不覆盖中央可走带。
- 空气：冷灰绿漫反射、较少强光束、更多水平水面亮带。
- 建筑：早段水位刻度，中段排水标记，末段半沉门庭与倒影缺口。
- 记忆画面：玩家沿低堤行走，左右水面把断裂门庭补成一个完整形状。
- 出口：盆地北缘的排水坡道开始持续抬升。

## 03 雾中山脊

- 高度：累计抬升至少 `18 m`，包含两段可读缓坡和一处鞍部。
- 可视距离：近景 `35–45 m`，远处塔体可穿过雾层露出轮廓。
- 地表：裸岩、薄土、冲刷沟和更少落叶。
- 植被：矮树、风折枝、草丛；林冠覆盖降低 `35–50%`。
- 空气：银灰雾层、明显侧风、低对比远山。
- 建筑：两个分离声盘与终点双塔轴线。
- 记忆画面：两座塔从不同雾层高度出现，声音先于完整轮廓抵达。
- 出口：双塔夹出的山口指向源头谷地。

## 04 水源圣所

- 高度：山口后展开为 `32–46 m` 宽的阶梯谷地。
- 可视距离：`70–100 m`，核心装置可被连续预告。
- 地表：人工台地、分级水道、湿石和少量回归植被。
- 植被：边缘密、轴线疏，树冠让位于建筑尺度。
- 水体：前景进水、两侧平衡渠、中央释放口构成一个连续系统。
- 空气：较明亮的冷绿天光与暖合金反射并存。
- 建筑：不再是单个地标，而是贯穿路线的完整水文装置。
- 记忆画面：玩家回望时发现前面三章的轴线在此汇成同一部机器。

## 四区域重建验收

1. 第一章与第二章使用不同固定地形、植被和遗迹种子。
2. 第二章出生后 `10 s` 画面包含浅水、低堤、较开放天空三项中的至少两项。
3. 第一章完整水门与正面瀑布构图不在第二章重复出现。
4. 第二章地图路线、玩家位置、浅水参照和地标均来自第二章真实世界坐标。
5. `390×844` 与 `320×568` 中央可走带连续，无水面或隐藏碰撞阻断。
6. low 档新增水面 draw calls 不超过 `3`，不新增全屏 pass。
7. 完成三条证据仍可抵达章节终点；观察、声音、暂停和存档合同不回归。
8. 第三章使用独立种子，路线累计抬升约 `11 m`，地表起伏为第一章约 `158%`，无第一章瀑布、深潭与溪流声；裸岩石鳍在终点双塔之前反复预告山脊地貌。
9. 第四章使用独立种子，地表起伏降至第一章约 `44%`，植被总密度约 `60%`，4 片长窄人工蓄水面与低矮石质渠沿贯穿路线，源头装置不再埋入第一章潭底高度。
10. 四章 terrain/vegetation seed 全部唯一；第二、三、四章不构建第一章 `RuinPlan`、瀑布镜面、喷雾粒子或其碰撞体。
