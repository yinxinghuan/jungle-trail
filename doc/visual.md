# 视觉规范

## 1. Visual thesis

- 游戏与受众：面向 AlterU 移动端玩家的第一人称程序化雨林探索。
- 情绪承诺：幽暗林径中的安静前行，逐渐被遗迹、光束与瀑布吸引。
- 一句话视觉命题：一台克制的自然纪录片摄影机，亲自穿过一座由代码生长出的湿润雨林。
- 标志性瞬间：从废墟阴影进入瀑布水池，斜向林冠光穿过水雾并照亮侵蚀石块。
- 必须具备：高密度植被层次、湿润且克制的电影色调、真实空间尺度。
- 避免方向：卡通丛林、霓虹赛博、通用玻璃拟态游戏 HUD。

## 2. Composition and camera

- 方向与比例：竖屏优先，同时支持横屏与桌面；主验收为 390×844、320×568。
- 相机：第一人称 58° 基准垂直视场，眼高 1.66 m；保留轻微步态、呼吸与手持漂移。
- 移动端镜头反馈优先于电影感：low 档运动模糊只保留约 `22%` 帧间曝光、4 次采样；转镜头时道路与石块轮廓必须快速收稳，不允许用长拖影掩盖低帧率。
- 移动端 low 档把场景内部像素比限制为 `0.72`、植被采样密度降到约桌面的 `50%`、叶片图集降为 `768 px`，并关闭景深；画面损失优先发生在远处叶片细节和镜头光学，不牺牲道路、石碑与遗迹轮廓。
- 主焦点：道路消失点、废墟开口和瀑布始终承担前进方向；第一章泥土带必须在近景、中景和下一处弯道至少保留一段连续可追踪轮廓。
- 层次：近景叶片与树干形成遮挡，中景路径和遗迹组织空间，远景由林冠、雾和光束封闭。
- HUD 安全区：顶部只放安静的地标进度与静音；底部左右分别留给移动与动作，中心 46% 画面不放常驻 UI。
- 注意路径：颜色更深的当前道路 → 弯道下一段漏光或人工轮廓 → 远处水声与瀑布。

## 3. Color

- 背景：`#05070A`；深林：`#111A13`；苔藓：`#71806B`；叶面高光：`#A9C98E`。
- 主文字：`#F0F3E9`；次文字：`#A7B19F`；暖光：`#D9C88E`；错误：`#D48B78`。
- 使用比例：场景色占 94% 以上；DOM 表面和文字不超过 6%。
- 禁止：高饱和纯绿、大面积黑色磨砂卡片、紫蓝渐变、无来源的霓虹辉光。

## 4. Typography

- 展示与 UI：系统无衬线 `ui-sans-serif, system-ui, -apple-system, "PingFang SC", "Noto Sans CJK SC", sans-serif`。
- 标题：24–30 px、300 字重、0.16em 字距、英文大写；中文不强制字距扩张。
- 正文：16 px、400 字重、1.5 行高；工具标签 11–12 px、600 字重、0.12em 字距。
- HUD 数字：等宽系统字体，使用 tabular numerals；不用厚描边、立体字或发光字。

## 5. Shape, material, and lighting

- 主形状来自叶片、藤蔓、树干和侵蚀石块；UI 使用窄矩形、细圆环和 8 px 以内小圆角。
- 第一处石碑必须以“直立矩形轮廓 + 古代合金圆嵌环”形成双重特征；合金主体为低亮度暖铜金，内缘有暗绿氧化缝，以真实金属反射对比湿石和植被，不自发光、不使用铬镜面或霓虹，目标周围以约 `3.4 m` 的低植被留白建立轮廓。
- 后续大型神庙或古代科技遗址沿用“湿暗石材承重 + 少量暖合金功能构件 + 绿锈年代痕迹”的材质语法；金属只标记被设计、连接或驱动的部分，不把整座遗址做成科幻飞船。
- 边框为 `1px rgba(216,228,209,.22)`；只允许轻微内阴影和场景对应的暗部遮蔽。
- 材质：湿石、泥土、树皮、薄叶与水雾；不引入塑料、金属铬或糖果质感。
- 林径泥土相对两侧落叶更暗、更湿、更连续，但边缘继续由噪声和落叶舌打破；禁止用发光边线、箭头贴花或均匀色带描路。
- 光线：暖色斜向直射光穿过冷绿林冠；体积光和雾保持局部而克制，阴影不能压成纯黑。

## 6. Characters, environments, and assets

- 保留上游程序化地形、16 类植物、废墟、瀑布与第一人称身体。
- 场景尺度、相机高度、路径宽度和地标顺序保持上游基准。
- 所有纹理、模型和声音继续由代码生成，不增加风格冲突的图片、GLB 或录音素材。
- 上游媒体截图只作为基线证据，不进入产品运行时。

## 7. UI and icons

- 图标：自绘 24×24、2 px 圆角描边 SVG；静音、声音、跳跃、冲刺、暂停和返回小径共用一致语法。
- 所有按钮触控目标至少 44×44 px；摇杆外环 104 px，内核 44 px。
- 入口首帧完成后直接展示真实雨林，标题与细边框文字动作退居底部暗部；不使用视频播放三角或遮住道路的居中卡片。
- 构建阶段按钮禁用并显示真实阶段；场景就绪后按钮文案保持“进入雨林”，状态提示改为“轻触，走进雨林”。
- 默认：暖白描边；按下：缩放至 0.94、边框提高；焦点：2 px 苔藓绿外框；禁用：35% 透明度。
- 加载：显示真实阶段与低成本森林剪影；成功：UI 淡出，让瀑布占据画面；错误：底部就近显示原因和重试。
- Emoji：禁止作为功能图标。

## 8. Motion and VFX

- 常规 UI 动效为 180–260 ms，使用 `cubic-bezier(.2,.8,.2,1)`；完成层为 700 ms 慢速淡入。
- 入口真实场景淡入后先停留 `0.6 s`，再进行一次 `3.6 s` 的低速水平观察，最大偏转约 `8°`；结束后停止 RAF 并用 6 个静止渲染清除运动模糊，点击后从该视角无缝恢复。
- 玩家输入同帧响应；摇杆内核跟手，不使用延迟弹簧。
- 场景 VFX 保留上游体积光、水雾、喷溅、叶片摆动、景深、克制泛光与运动模糊。
- 禁止屏幕震动和玩法命中冻结；入口待机允许以停止 RAF 的方式保留静态 WebGL 帧，完成只通过环境音、水雾亮度和安静排版提升。
- `prefers-reduced-motion` 下关闭幽灵手势循环和 UI 位移，保留必要状态变化；场景头部摆动降低 70%。

## 9. References translated into principles

- 参考：StarKnightt / Jungle Trail，上游 revision `753fb347328ce49963d8ae96124d5224f980bf63`。
- 有用原则：程序化资产共享同一噪声、光照与材质逻辑，因此画面高度统一。
- 改造：保持视觉引擎和地标结构，补齐移动触控、竖屏构图、生命周期与分级性能。
- 不复制：桌面专属 Pointer Lock 入口、F3 调试 UI、数字键传送作为产品交互。

## 10. Anti-patterns

- 禁止 Emoji、彩色扁平图标、混用线性和填充图标。
- 禁止霓虹描边、渐变按钮、大片玻璃卡、夸张发光、彩纸奖励和游戏化金币。
- 禁止为了外部访客栏永久下移相机或缩小游戏主体。
- 禁止把完成状态做成遮住瀑布的居中大弹窗。
- 禁止将头像贴在 HUD 或把用户名刻进场景来伪造个性化。

## 11. Vertical-slice acceptance

- 入口：深林剪影即时可见；页面可见后自动生成，首帧完成后真实雨林接管背景，短暂观察后冻结待进入。
- 游戏：390×844 可同时完成移动、观察、跳跃和冲刺，中心道路不被 UI 遮挡。
- 高反馈：抵达遗迹/瀑布时地标进度、环境音与场景变化一致，不出现通用奖励特效。
- 完成：瀑布保持可观察，完成文字与操作退居安全区。
- 窄屏：320×568 无横向溢出，按钮至少 44×44，顶部与底部安全区不冲突。
- 观察切片：390×844 与 320×568 均能看清“附近—对准—完成”三态；观察环不与幽灵手势、摇杆、跳跃、冲刺和顶部操作重叠。
- QA 决策：首轮真实截图后记录 P0/P1，修复并以同一地标、同一视角复验。

## 屏幕与状态合同

### 全局环境

- 混合界面：全屏响应式 WebGL + 响应式 DOM HUD。
- 状态：sleeping、building、preview、ready-frozen、exploring、paused、completed、error。
- 平台内无访客栏为主构图；外部访客栏只做可用性检查。

### Sleeping / Building

- 玩家问题：这是什么，值得启动吗？
- 主焦点：幽暗林径剪影与标题；页面可见后自动开始真实构建，入口按钮在首帧前禁用。
- 加载失败：显示明确错误和可点击重试，不留下空白画布。

### Preview / Ready frozen

- 玩家问题：这里值得走进去吗？
- 主焦点：真实雨林道路与光线；标题、说明和入口动作位于底部暗部，不遮挡道路消失点。
- 反馈：场景进行一次短镜头观察后停止 RAF；按钮始终保留明确静态文案，reduced-motion 直接进入冻结态。

### Exploring

- 玩家问题：往哪里走、怎样移动？
- 主焦点：道路和场景；左摇杆、右拖拽视角；跳跃/冲刺为次动作。
- 常驻信息：安静的五段地标进度、静音和暂停。
- 观察切片：进入第一处石迹的 `22 m` 范围后，中心出现 56 px 缺口观察环；环只用暖白/苔藓描边、无玻璃底板，完成后顶部路程条下方的“线索 1/1”变为稳定暖白。
- 远距预告：进入第一石迹 `38 m` 范围时只让顶部线索菱形呼吸一次，并在顶部安全区下显示 `3.2 s` 场景化文字；不出现发光描边或悬浮目标图标。
- 防卡提示：在线索范围停留 `4.5 s` 仍未对准时，观察环外沿显示一枚方位短刻度，并明确提示寻找“带圆形刻痕的直立石碑”；它只提供方向，不覆盖或框选答案。
- 偏航恢复：离开泥土中心 `1.2 s` 后，在触控区上方显示一行“较暗的小径在左/右侧”；回到道路后同帧淡出，不与观察文字同时出现。
- 观察反馈：对准时圆环在 `120 ms` 后开始收束，偏离先保留 `0.35 s` 再回退；成功文字位于顶部安全区以下、画面中轴上方，不遮挡触控区和道路近景。
- 引导：幽灵手势先演示右侧拖动，再演示左侧移动；玩家完成对应动作后永久消失。

### Paused

- 玩家问题：如何继续或恢复位置？
- 动作：继续、回到小径、静音；不遮满场景。

### Completed

- 玩家问题：我到了哪里，接下来做什么？
- 主焦点：瀑布；动作：继续观察、重新步行。

- 静音与 reduced-motion 下，所有状态仍通过文字、边框和位置读得出来。
