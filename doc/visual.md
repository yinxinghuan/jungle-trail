# 视觉规范

## 1. Visual thesis

- 游戏与受众：面向 AlterU 移动端玩家的第一人称程序化雨林探索。
- 情绪承诺：幽暗林径中的安静前行，逐渐被遗迹、光束与瀑布吸引。
- 一句话视觉命题：一台克制的自然纪录片摄影机，亲自穿过一座由代码生长出的湿润雨林。
- 标志性瞬间：玩家从密林中第一次看见巨型水门，暖铜金合金槽在湿暗石面与瀑布雾光之间形成一条克制但明确的人造轴线。
- 必须具备：高密度植被层次、湿润且克制的电影色调、真实空间尺度。
- 界面方向：野外调查仪器——像一套随身测绘板与旧式水文记录器，不像手机操作系统，也不照搬参考图中的沙漠、货币和战斗栏。
- 避免方向：卡通丛林、霓虹赛博、通用玻璃拟态游戏 HUD、只剩两条文字与圆形按钮的临时原型感。

## 2. Composition and camera

- 方向与比例：竖屏优先，同时支持横屏与桌面；主验收为 390×844、320×568。
- 相机：第一人称 58° 基准垂直视场，眼高 1.66 m；保留轻微步态、呼吸与手持漂移。
- 移动端镜头反馈优先于电影感：low 档运动模糊只保留约 `22%` 帧间曝光、4 次采样；转镜头时道路与石块轮廓必须快速收稳，不允许用长拖影掩盖低帧率。
- 移动端 low 档把场景内部像素比限制为 `0.72`、植被采样密度降到约桌面的 `50%`、叶片图集降为 `768 px`，并关闭景深；画面损失优先发生在远处叶片细节和镜头光学，不牺牲道路、石碑与遗迹轮廓。
- 主焦点：道路消失点、废墟开口和瀑布始终承担前进方向；第一章泥土带必须在近景、中景和下一处弯道至少保留一段连续可追踪轮廓。
- 层次：近景叶片与树干形成遮挡，中景路径和遗迹组织空间，远景由林冠、雾和光束封闭。
- HUD 安全区：顶部左侧为调查牌，右侧为工具栏；底部左右分别留给模拟摇杆与跳跃，中心 54% 画面不放常驻面板。
- 注意路径：颜色更深的当前道路 → 弯道下一段漏光或人工轮廓 → 远处水声与瀑布。
- 四章构图递进：第一章水平水门轴线；第二章现实门体与水面倒影上下拼合；第三章双塔夹住雾中山谷；第四章阶梯立面包围中央水源装置。
- 宏观地标首次可见时必须占屏幕短边至少 `10%`，进入调查区后主要结构占 `24–55%`；不能只在远处露出几像素尖顶。

## 3. Color

- 背景：`#05070A`；深林：`#111A13`；苔藓：`#71806B`；叶面高光：`#A9C98E`。
- 主文字：`#F0F3E9`；次文字：`#A7B19F`；暖光：`#D9C88E`；错误：`#D48B78`。
- 古代合金：基色 `#B18D55`；高光 `#D5B77B`；氧化缝 `#365C4A`；水下合金压暗至 `#665A42`。
- 调查仪器：深墨绿 `#101A17`；纸张 `#D8D1B8`；纸墨 `#27352F`；铜刻度 `#B18D55`；激活氧化绿 `#71A189`。
- 使用比例：场景仍为绝对主体；常驻 UI 只占四角，地图仅在玩家主动打开时覆盖画面。
- 禁止：高饱和纯绿、大面积黑色磨砂卡片、紫蓝渐变、无来源的霓虹辉光。

## 4. Typography

- 展示与 UI：系统无衬线 `ui-sans-serif, system-ui, -apple-system, "PingFang SC", "Noto Sans CJK SC", sans-serif`。
- 标题：24–30 px、300 字重、0.16em 字距、英文大写；中文不强制字距扩张。
- 正文：16 px、400 字重、1.5 行高；工具标签 11–12 px、600 字重、0.12em 字距。
- HUD 数字：等宽系统字体，使用 tabular numerals；不用厚描边、立体字或发光字。

## 5. Shape, material, and lighting

- 主形状来自叶片、藤蔓、树干和侵蚀石块；UI 使用窄矩形、直角括号、纸张切角、细刻度和 6 px 以内小圆角。
- 第一处石碑必须以“直立矩形轮廓 + 古代合金圆嵌环”形成双重特征；合金主体为低亮度暖铜金，内缘有暗绿氧化缝，以真实金属反射对比湿石和植被，不自发光、不使用铬镜面或霓虹，目标周围以约 `3.4 m` 的低植被留白建立轮廓。
- 后续大型神庙或古代科技遗址沿用“湿暗石材承重 + 少量暖合金功能构件 + 绿锈年代痕迹”的材质语法；金属只标记被设计、连接或驱动的部分，不把整座遗址做成科幻飞船。
- 第一章金属标记“轴线与连接”；第二章标记“水位与闸槽”；第三章标记“共鸣与方向”；第四章把前三种功能语言汇入中央水源装置。
- 合金可使用真实 PBR 反射变化，但不可自发光；绿锈覆盖不能超过单个功能构件可见面积的 `45%`，否则再次失去材质反差。
- 边框为 `1px rgba(216,228,209,.22)`；只允许轻微内阴影和场景对应的暗部遮蔽。
- 材质：湿石、泥土、树皮、薄叶与水雾；不引入塑料、金属铬或糖果质感。
- 林径泥土相对两侧落叶更暗、更湿、更连续，但边缘继续由噪声和落叶舌打破；禁止用发光边线、箭头贴花或均匀色带描路。
- 光线：暖色斜向直射光穿过冷绿林冠；体积光和雾保持局部而克制，阴影不能压成纯黑。

## 6. Characters, environments, and assets

- 保留上游程序化地形、16 类植物、废墟、瀑布与第一人称身体。
- 第一章场景尺度、相机高度、路径宽度和原地标顺序保持上游基准；新增水门在现有 gate、terrace、cella、revetment 语法上扩展。
- 第二至四章继续用同一套程序化地形、植被、废墟和水体生成方式创建新布局，不导入风格不一致的传统关卡包。
- 每章只加载当前世界；章节选择画面使用已完成场景的静态真实帧或低成本程序剪影，不同时保持四个 WebGL 世界。
- 所有纹理、模型和声音继续由代码生成，不增加风格冲突的图片、GLB 或录音素材。
- 上游媒体截图只作为基线证据，不进入产品运行时。

## 7. UI and icons

- 图标：自绘 24×24、2 px 圆角描边 SVG；地图、静音、声音、跳跃、暂停和返回小径共用一致语法。移动端不再出现冲刺按钮。
- 所有按钮触控目标至少 44×44 px；摇杆外环 112 px，内核 44 px，并增加 62% 步行/快走分界刻度。
- 顶部调查牌：深墨绿半透明底、左侧章节徽记、右侧两行信息；第一行是地标名与路线百分比，第二行是细进度轨与线索 `n/3`。两端用直角括号和铜金小刻度建立仪器感。
- 右上工具栏：地图、声音、暂停纵向排列在一条细框导轨内；激活状态使用氧化绿实心小标，不靠发光。
- 地图面板：全屏深绿遮罩上放暖灰折叠纸，纵向手绘式路线从林径入口通向地标；玩家是带方向缺口的铜金圆针，线索是菱形测绘钉，已记录填充、未发现空心、当前目标带双圈。
- 地图下方列出当前目标和章节总览；章节使用 I–IV 节点串联，锁定、可进入和完成同时以线型与文字表达。地图不显示精准 GPS 坐标，保留探索感。
- 信息层级：常驻 HUD 只回答“我在哪一章、走了多远、找到多少、工具在哪”；任务提示短暂出现；完整线索说明只在记录瞬间出现；地图承接详细路线信息。
- 入口首帧完成后直接展示真实雨林，标题与细边框文字动作退居底部暗部；不使用视频播放三角或遮住道路的居中卡片。
- 构建阶段按钮禁用并显示真实阶段；场景就绪后按钮文案保持“进入雨林”，状态提示改为“轻触，走进雨林”。
- 默认：暖白描边；按下：缩放至 0.94、边框提高；焦点：2 px 氧化绿外框；禁用：35% 透明度。
- 加载：显示真实阶段与低成本森林剪影；成功：UI 淡出，让瀑布占据画面；错误：底部就近显示原因和重试。
- 多章节入口：实时章节场景仍是主视觉；标题下方用 4 个紧凑编号槽显示当前、可进入和锁定章节，不加载额外静帧或第二个 WebGL 世界。
- 当前章节同时通过编号、描边和标题表达；锁定项禁用并显示“未解锁”，章节切换使用 `click` 后整页释放上一世界。
- 本章证据使用同一缺口菱形与 `n/3` 文字计数；记录、附近和完成状态同时通过形状、进度与文字表达，不只换颜色。
- 调查模式入口只在章节通关后出现；结果使用“证据 / 时间 / 提示 / 偏航恢复”四列安静记录，不出现评级章和奖杯。
- Emoji：禁止作为功能图标。

## 8. Motion and VFX

- 常规 UI 动效为 180–260 ms，使用 `cubic-bezier(.2,.8,.2,1)`；完成层为 700 ms 慢速淡入。
- 入口真实场景淡入后先停留 `0.6 s`，再进行一次 `3.6 s` 的低速水平观察，最大偏转约 `8°`；结束后停止 RAF 并用 6 个静止渲染清除运动模糊，点击后从该视角无缝恢复。
- 玩家输入同帧响应；摇杆内核跟手，不使用延迟弹簧。位移 `12–62%` 进入步行曲线，`62–100%` 连续抬升到快走，跨越分界线时只让状态文字和外圈刻度在 `160 ms` 内变化。
- 场景 VFX 保留上游体积光、水雾、喷溅、叶片摆动和克制泛光；low 关闭景深与运动模糊，high 将运动快门降至 `0.28`，避免操作拖滞和眩晕。
- 禁止屏幕震动和玩法命中冻结；入口待机允许以停止 RAF 的方式保留静态 WebGL 帧，完成只通过环境音、水雾亮度和安静排版提升。
- `prefers-reduced-motion` 下关闭幽灵手势循环和 UI 位移，保留必要状态变化；场景头部摆动降低 70%。
- 地图打开使用 `220 ms` 纸张展开与遮罩淡入；关闭时反向收起。减少动态模式下只做 1 ms 淡入淡出，不移动纸张。
- 章节切换不做连续穿越动画；旧世界淡出 `300 ms`、释放后显示章节构建状态，新世界首帧握手后淡入 `700 ms`，避免多世界同时占用 GPU。
- 宏观地标完成反馈只改变已有水、雾、真实反射和声场，持续 `420–1200 ms`；禁止整座建筑发光、升起或旋转。

## 9. References translated into principles

- 参考：StarKnightt / Jungle Trail，上游 revision `753fb347328ce49963d8ae96124d5224f980bf63`。
- 有用原则：程序化资产共享同一噪声、光照与材质逻辑，因此画面高度统一。
- 改造：保持视觉引擎和地标结构，补齐移动触控、竖屏构图、生命周期与分级性能。
- 不复制：桌面专属 Pointer Lock 入口、F3 调试 UI、数字键传送作为产品交互。
- 用户参考一：提炼顶部地区状态牌、底部工具入口和低多边形场景之上的高对比信息层；不复制货币、战斗技能或沙漠色调。
- 用户参考二：提炼直角括号、模块化工具槽与明确选中状态；不复制邀请、治疗或背包战斗逻辑。
- 用户参考三：提炼折叠纸地图、节点路线、当前位置针和“发现目标”的旅程感；改造成单章实时测绘地图，不做静态关卡选择海报。

## 10. Anti-patterns

- 禁止 Emoji、彩色扁平图标、混用线性和填充图标。
- 禁止霓虹描边、渐变按钮、大片玻璃卡、夸张发光、彩纸奖励和游戏化金币。
- 禁止把地图做成无状态截图、雷达小圆盘或精确 GPS 导航；禁止让地图常驻遮住场景。
- 禁止为了外部访客栏永久下移相机或缩小游戏主体。
- 禁止把完成状态做成遮住瀑布的居中大弹窗。
- 禁止将头像贴在 HUD 或把用户名刻进场景来伪造个性化。

## 11. Full-product acceptance

- 入口：深林剪影即时可见；页面可见后自动生成，首帧完成后真实雨林接管背景，短暂观察后冻结待进入。
- 游戏：390×844 可同时完成慢走/步行/快走、观察和跳跃，中心道路不被 UI 遮挡。
- 高反馈：抵达遗迹/瀑布时地标进度、环境音与场景变化一致，不出现通用奖励特效。
- 完成：瀑布保持可观察，完成文字与操作退居安全区。
- 窄屏：320×568 无横向溢出，按钮至少 44×44，顶部与底部安全区不冲突。
- 四章：每章在首次接近时先读到宏观地标，再读到中观方向，最后读到微观证据；不能依赖 UI 才理解目标区域。
- 观察：390×844 与 320×568 均能看清“附近—对准—完成”三态；观察环不与幽灵手势、摇杆、跳跃和顶部操作重叠。
- 地图：两种尺寸均显示玩家位置、3 条线索、终点和 I–IV 章节轨；打开时世界暂停、关闭后原地继续。
- 章节选择：320×568 可同时看到全部 4 个编号槽，锁定和当前状态清晰；列表项使用点击而不是触碰触发。
- 调查模式：随机目标、提示强度和结算记录在两种语言下不溢出，熟练调查不改变场景艺术方向。
- 性能：每次只存在一个章节 WebGL 世界；low 档无新增全屏 pass，第二章倒影不触发完整镜面重渲染。
- QA 决策：首轮真实截图后记录 P0/P1，修复并以同一地标、同一视角复验。

## 屏幕与状态合同

### 全局环境

- 混合界面：全屏响应式 WebGL + 响应式 DOM HUD。
- 状态：sleeping、building、preview、ready-frozen、chapter-select、exploring、map、paused、chapter-complete、survey-select、survey-complete、error。
- 平台内无访客栏为主构图；外部访客栏只做可用性检查。

### Sleeping / Building

- 玩家问题：这是什么，值得启动吗？
- 主焦点：幽暗林径剪影与标题；页面可见后自动开始真实构建，入口按钮在首帧前禁用。
- 加载失败：显示明确错误和可点击重试，不留下空白画布。

### Preview / Ready frozen

- 玩家问题：这里值得走进去吗？
- 主焦点：真实雨林道路与光线；标题、说明和入口动作位于底部暗部，不遮挡道路消失点。
- 反馈：场景进行一次短镜头观察后停止 RAF；按钮始终保留明确静态文案，reduced-motion 直接进入冻结态。

### Exploring

- 玩家问题：往哪里走、怎样移动？
- 主焦点：道路和场景；左摇杆同时选择方向与速度、右拖拽视角；跳跃为次动作。
- 常驻信息：调查牌显示章节、地标、路线和线索；右侧工具轨提供地图、静音和暂停。
- 观察切片：进入当前证据范围后，中心出现 56 px 缺口观察环；环只用暖白/苔藓描边、无玻璃底板，每次记录更新顶部“线索 n/3”，三条完成后变为稳定暖白。
- 远距预告：进入第一石迹 `38 m` 范围时只让顶部线索菱形呼吸一次，并在顶部安全区下显示 `3.2 s` 场景化文字；不出现发光描边或悬浮目标图标。
- 防卡提示：在线索范围停留 `4.5 s` 仍未对准时，观察环外沿显示一枚方位短刻度，并明确提示寻找“带金属圆环的直立石碑”；它只提供方向，不覆盖或框选答案。
- 偏航恢复：离开泥土中心 `1.2 s` 后，在触控区上方显示一行“较暗的小径在左/右侧”；回到道路后同帧淡出，不与观察文字同时出现。
- 观察反馈：对准时圆环在 `120 ms` 后开始收束，偏离先保留 `0.35 s` 再回退；成功文字位于顶部安全区以下、画面中轴上方，不遮挡触控区和道路近景。
- 引导：幽灵手势先演示右侧拖动，再演示左侧移动；玩家完成对应动作后永久消失。
- 本章有三条证据；顶部只显示当前章节地点和三枚证据符号，不显示四章总进度，避免 HUD 变成任务面板。

### Map

- 玩家问题：我走到哪里、下一条证据大致在哪、整段调查还剩多少？
- 打开后暂停场景、音频和观察计时；折叠纸路线显示实时玩家针、3 条线索的当前/未测绘/已记录状态、目的地和四章解锁轨。
- 地图不显示精确米数或导航箭头；关闭按钮、遮罩、M 与 Escape 均可返回探索，位置和视角保持不变。

### Chapter select

- 玩家问题：继续哪里、下一章是什么？
- 主焦点：当前章节实时雨林预览与章节问题。
- 主动作：进入当前章节；次动作：切换已解锁章节。完成后从结算进入测绘挑战。
- 四个编号槽在 320×568 不滚动；锁定章节为 disabled button，错误或无存档时第一章始终可进入。

### Paused

- 玩家问题：如何继续或恢复位置？
- 动作：继续、回到小径、静音；不遮满场景。

### Chapter complete

- 玩家问题：三条证据说明了什么，接下来去哪里？
- 主焦点：当前大型地标与一句章节结论；动作优先级为下一章、调查本章、继续观察。
- 未完整结论明确显示略过证据，但不使用红色失败语言。

### Survey select / complete

- 玩家问题：这次调查的目标和结果是什么？
- 选择态只提供安静调查/熟练调查两种模式；完成态显示 3/3、时间、提示与偏航恢复。
- 不显示全球排行榜、奖励货币或每日次数。
