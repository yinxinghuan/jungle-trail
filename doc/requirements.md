# 需求文档

## 1. Overview

《Jungle Trail》是一款由 4 个独立章节组成的第一人称程序化雨林侦察冒险：玩家沿水系深入失落遗址，通过轮廓、古代合金、反射、方向声和空间关系记录每章 3 条证据，最终理解整套建筑是一台跨越山谷的水文装置。

### 界面简报

- 玩家：AlterU 信息流中的移动端玩家，也支持桌面浏览器。
- 单章时长：第一章 `7–9 min`，第二、三章各 `6–8 min`，第四章 `8–10 min`。
- 完整主线：`28–35 min`，章节独立解锁，不要求一次完成。
- 核心交互：左侧移动、右侧观察、稳定镜头；不增加常驻互动按钮。
- 情绪承诺：从“发现一块不自然的石碑”逐步扩大到“看懂一套隐藏在雨林中的古代水文机器”。
- 主要目标：每章完成 3 条主线证据并形成章节结论；通关后开放该章调查模式。
- 目标平台：AlterU WebView、移动 Safari/Chrome、桌面浏览器；竖屏主验收为 390×844 与 320×568。
- 明确不做：战斗、生命值、金币、掉落物、星级、全球排行榜、常驻地图/罗盘和科幻霓虹机关。

### 章节

1. 被吞没的小径：通过路旁标记、水门轴线和瀑布缺口确认道路是人工水路。
2. 涨水的门址：通过水位环、反射门形和泄水槽确认建筑用于测量涨水。
3. 雾中的高地：通过共鸣柱、双塔声盘和山谷交点确认高地在监听上游。
4. 水源圣所：按水流顺序验证进水环、导流槽与水源装置，完成整套遗址结论。

## 2. Visual Design

- 视觉主体始终是程序化雨林、湿石遗址、水、雾与林冠光；DOM UI 不超过画面视觉面积的 `6%`。
- 四章共享“湿暗石材承重 + 少量暖铜金古代合金构件 + 暗绿氧化缝”的人造物语言。
- 每章必须有一个从 `60–120 m` 外可感知的大型地标：水门遗址、半沉门庭、雾中观测台、水源装置。
- 宏观地标负责吸引和定向；中观材质/声场负责接近；微观证据负责验证。禁止让一个小物件独自承担整段导航。
- 第一章水门约 `10–12 m` 宽、残高 `5–6.5 m`；第二章门庭约 `12–15 m` 宽、残高 `7–9 m`；第三章双塔高 `14–18 m`；第四章装置约 `20–26 m` 宽、残高 `12–16 m`。
- 关键目标从主要接近路线看，屏幕高度不得低于短边 `6%`，高植被遮挡不超过 `40%`，周围保留 `2.8–4.0 m` 低植被负空间。
- 入口仍先展示真实章节场景，完成短镜头观察后停止 RAF；点击只接管控制并解锁音频。
- HUD 使用暗叶绿、苔藓灰、暖白和克制暖金属色；功能图标全部使用同一套 2px 描边 SVG，禁止 Emoji。
- 章节结算退居底部安全区，保留大型地标继续可观察，不使用遮满画面的结果卡。
- 原作没有可替换的照片或文字输入，不强行加入玩家头像或用户名。

## 3. Game Mechanics

### 3.1 通用移动与路径

- 第一章保留 423.8 米路径和出生进度 `0.02`；后续章节路径目标长度为 `280–420 m`。
- 摇杆输入幅度映射到 `0–100%` 移动速度；冲刺为按住状态，跳跃只接受落地边缘触发。
- 粗指针设备在距路径中心 `7.5 m` 内、前向输入至少 `45%` 且横向输入低于 `45%` 时启用柔性路径辅助，最高修正 `50%`，不旋转相机。
- 离路超过 `2.4 m` 持续 `1.2 s` 显示方向恢复提示；回到 `1.5 m` 内隐藏。
- 每章保存最近安全路径点；暂停页“回到最近调查点”只恢复位置，不完成证据。

### 3.2 证据与观察

- 每章有 3 条主线证据；同一时刻只计算当前证据，不遍历全部场景对象。
- 通用对准半径为屏幕短边 `9%`，脱离半径 `14%`，对准防抖 `120 ms`，偏离宽限 `0.35 s`。
- 第一章稳定时间为 `1.1–1.3 s`；第二章 `1.3 s`；第三章单目标 `1.0 s`；第四章 `1.2–1.4 s`。
- 冲刺、暂停、页面隐藏、场景离屏、入口预览和章节切换期间不累积观察进度。
- 证据完成后本章不可重复触发；略过的证据不算完成，但不阻止玩家抵达章节终点。
- 每条证据至少同时使用两种可读特征：轮廓、材质、负空间、反射、声音或运动。

### 3.3 分章规则

- 第一章证据 1：`38 m` 预告、`22 m` 有效距离，稳定 `1.1 s`。
- 第一章证据 2：玩家进入宽 `4.5 m` 的安全观察带，使门柱、门楣和瀑布轴线对齐，稳定 `1.3 s`。
- 第一章证据 3：观察两侧堤翼与中央 `16–17 m` 水流缺口，稳定 `1.2 s`。
- 第二章反射证据必须位于宽 `3.5 m` 的观察带内；移动 low 档不能开启完整场景镜面重渲染。
- 第三章先记录左右两个方向声证据，再在高地完成交点验证；静音状态提供等价的视觉方向脉冲。
- 第四章按进水环 → 导流槽 → 中央装置顺序验证；顺序错误不失败，只保留已理解的连续前缀并给出空间提示。

### 3.4 提示与公平性

- 每个调查区首先提供自然提示，不显示常驻箭头。
- 第一至第四章首次轻 UI 帮助分别在 `4.5 / 6 / 7 / 8 s` 后出现。
- 轻帮助显示观察环外缘方位短刻度，并描述可验证特征，不直接框选目标。
- 在区域停留 `15 s` 或越过目标 `20–24 m` 后升级为明确恢复提示，说明目标位于身后、高处或水面。
- 暂停页提供“自然 / 清晰”提示强度；清晰模式把首次帮助提前 `2 s`，不扩大完成判定。
- 玩家可以略过证据；章节结论显示完整或未完整版本，不使用失败字样。

### 3.5 章节与调查模式

- 首次进入直接开放第一章；完成一章后开放下一章和本章调查模式。
- 调查模式每章从 `6–8` 个经过验证的语义锚点中抽取 `3` 个，至少覆盖两种观察规则。
- 安静调查保留主线提示，不计成绩；熟练调查把首次 UI 帮助延后 `4 s`，记录时间、提示次数和偏航恢复次数。
- 调查模式不生成新故事、不移动关键建筑、不使用完全随机线索；非关键植被、雾、落叶与天气可以使用安全种子变化。
- 只保存个人最好调查记录，不接全球排行榜。

### 3.6 进度与存档

- 保存已解锁章节、章节完成状态、调查模式个人最好记录、提示偏好和语言。
- 存档失败不能阻塞游玩；本次会话结果继续显示，并提供非阻塞重试。
- 重新开始章节只重置当前章节证据和用时，不锁回后续已解锁章节。

### 3.7 性能与生命周期

- 移动端初始 low、桌面初始 high；low 保持最高 `0.72` 像素比、`50%` 植被密度、`768 px` 叶片图集、4 级泛光、4-tap / `0.22` 帧运动采样并关闭景深。
- 移动 low 连续 `1.6 s` 低于约 `39 fps` 时从 60 fps 目标回退到 30 fps。
- 任意时刻只加载一个章节世界；切章必须释放上一章 GPU 资源、RAF、Worker 与音频节点。
- 每章相对第一章 low 档稳定 draw calls 增量不超过 `8`；宏观地标额外三角形 high 不超过 `60k`、low 不超过 `28k`。
- 单章新增全屏后处理 pass 数量为 `0`；玩法系统相对纯场景基线持续帧率下降不超过 `1 fps`。
- 页面隐藏或游戏可见面积低于 `15%` 时暂停 RAF、音频、观察和动态模拟。
- WebGL、章节构建或音频失败分别显示可恢复错误；音频失败不阻塞探索。

## 4. Controls

- 移动端左摇杆：`pointerdown` 捕获，最大拖动半径 `52 px`，`pointermove` 更新向量，`pointerup/cancel` 归零。
- 移动端右侧观察区：单指拖动改变 yaw/pitch；每 1 CSS px 约 `0.0032 rad`，俯仰限制 `-1.35–1.35 rad`。
- 跳跃：44×44 px 以上按钮使用 Pointer Events，落地时一次触发。
- 冲刺：按住开始，`pointerup/cancel/leave` 结束；冲刺时不累积观察。
- 观察：不增加按钮；将目标保持在中心观察区自动累积。
- 章节选择、调查模式列表等可滚动 UI 使用 `onClick`，不能用触碰即触发的 `pointerdown`。
- 桌面：Pointer Lock 鼠标观察，WASD 移动，Shift 冲刺，Space 跳跃，Escape 暂停。
- iOS：全局禁止长按 callout、文字选择和图片拖动；真实文本编辑控件恢复选择行为。

## 5. Win / Lose Conditions

- 章节完成条件：抵达章节终点，并完成或明确略过 3 条主线证据。
- 完整结论：3 条证据全部记录；未完整结论：至少 1 条略过。
- 章节结果显示三条证据、章节用时、提示次数，以及下一章、调查本章、继续观察三个动作中当前可用项。
- 第四章完整结论后显示总旅程结语与章节回看；不播放排行榜或星级评价。
- 调查模式完成条件：记录本局抽取的 3 个目标；结算显示用时、提示次数和偏航恢复次数。
- 游戏没有死亡、生命值或强制重开；碰撞、陡坡和水体只阻止或修正移动。
- WebGL/构建失败属于技术错误状态，提供重试或返回章节选择，不进入失败结算。

## 6. Sound Effects

- 首次主动进入：点击后解锁 AudioContext；入口自动预览始终静音。
- 脚步：按地表与步态触发 `80–240 ms` 程序化脚步，音量随步速变化。
- 环境：风、昆虫、鸟声、水流使用互质时长循环，单层约 `9.31–16.41 s`，避免明显共同周期。
- 调查区域：进入时播放一次约 `300–420 ms` 的材质/方向声，峰值不超过 master `0.06`。
- 记录证据：石材/金属/水/风分别使用不同的两层短音，约 `360–520 ms`，峰值不超过 master `0.08`，配合 `20 ms` 触觉。
- 第二章反射拼合：加入约 `480 ms` 的水面高频收束，不盖过环境水声。
- 第三章声盘：左右目标使用可区分的 `180–260 Hz` 基频与空间位置；静音时视觉方向脉冲等价可用。
- 第四章顺序完成：三段声音按低 → 中 → 高叠合，最终水声在 `1.2 s` 内展开，配合 `35 ms` 触觉。
- 暂停/隐藏：立即平滑衰减并挂起；恢复后不补播离线事件。
- 音频失败：保持静音体验，所有必要信息仍由视觉和文字表达。
