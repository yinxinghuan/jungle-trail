# 需求文档

## 1. Overview

《Jungle Trail》是一段 6–10 分钟的第一人称程序化雨林观察体验：玩家沿 423.8 米林间路径穿过植被与废墟，通过稳定镜头记录一处早期人工石迹，再抵达瀑布完成旅程；本轮以这一处线索验证后续三章观察玩法。

### 界面简报

- 玩家与场景：AlterU 信息流中的移动端玩家，通常单手或双手持机，可能只停留 10 秒，也可以完成整段探索。
- 核心交互：左侧触控移动、右侧拖动观察；桌面保留 WASD、鼠标视角、Shift 冲刺与 Space 跳跃。
- 情绪承诺：从幽暗、潮湿、封闭的林径逐步走进遗迹与光瀑，获得一次安静而有方向感的发现。
- 主要目标：沿路前进、主动辨认不属于森林的人工形状，完成第一处观察并抵达瀑布终点。
- 目标平台：AlterU WebView、移动 Safari/Chrome、桌面浏览器；竖屏优先，验证 390×844 与 320×568。
- 明确不做：倒计时、生命值、计分、排行榜、强制头像或用户名装饰、通用玻璃卡片 UI。

## 2. Visual Design

- 视觉主体始终是程序化雨林：密集植被、湿润土路、侵蚀石块、林冠漏光、体积雾和瀑布。
- 采用全屏响应式 WebGL 画布，DOM 只承担启动、触控、静音、进度提示、错误恢复与完成状态。
- 页面在真实可见后自动构建雨林；构建期间保留低成本深林剪影与真实阶段文案，首帧完成后立即把真实 WebGL 场景作为入口主体。
- 入口场景淡入后先保留 `0.6 s` 建立镜头，再进行一次 `3.6 s` 的克制镜头观察，随后停止 RAF 并保留最后一帧；玩家点击只负责接管控制、显示 HUD 与解锁声音。
- HUD 使用暗叶绿、苔藓灰与暖白，面积保持克制，不遮挡画面中心与道路消失点。
- 第一处线索进入有效距离后，画面中心显示 56 px 缺口观察环；完成后在顶部进度下方保留一个安静的已记录符号，并以非模态文字呈现观察结论。
- 所有功能图标使用同一套 2px 描边 SVG；禁止 Emoji 功能图标。
- 原作不包含可替换的示例照片或文字输入，因此不强行把玩家头像或用户名放入视觉主体。

## 3. Game Mechanics

- 世界路径长度保持 423.8 米，出生点位于路径归一化进度 `0.02`。
- 第一章前半段的可读泥土带相对现版向两侧各扩大约 `0.18–0.24 m`，中央泥土与落叶边缘的明暗差至少提高 `12%`；这只增强道路辨识，不把林径改成规则直线或宽路。
- 第一线索前的观察走廊清除宽度超过 `1.2 m` 的高遮挡灌木，并在目标周围 `2.4 m` 内压低大型阔叶与幼树密度；地表落叶、蕨类和林冠仍保留。
- 行走、慢跑、重力、跳跃、坡度与碰撞沿用上游基准；触控摇杆幅度映射到 `0–100%` 移动输入。
- 粗指针设备在玩家位于路径中心 `7.5 m` 内、摇杆向前至少 `45%` 且横向输入低于 `45%` 时启用柔性路径辅助：道路中心修正最高 `38%`，偏到 `3.2 m` 外时可升至 `50%`；只有当前朝向与前方路径夹角小于 `90°` 才生效，不旋转相机，不处理后退、横移、桌面键盘或观察停留。
- 玩家持续离开泥土中心超过 `2.4 m` 达 `1.2 s` 后显示一次方向性恢复文字；回到 `1.5 m` 内立即隐藏，不画常驻箭头，也不自动传送。
- 右侧拖动每 1 CSS px 产生约 `0.0032 rad` 的视角变化；俯仰限制为 `-1.35–1.35 rad`。
- 冲刺按钮按住期间使用慢跑速度，释放后恢复步行；跳跃按钮只在落地状态接受一次触发，按住不能连续兔跳。
- 旅程进度由玩家在路径上的最近归一化位置估算，UI 只显示 5 个地标阶段，不显示竞争分数。
- 玩家首次进入瀑布终点区域（路径进度至少 `0.955`）触发完成；完成后画面继续运行并保留自由观察，可选择重新步行。
- 第一处观察目标位于路径进度约 `0.356` 的直立加工石块；玩家距目标不超过 `18 m` 时启用观察判定。
- 玩家首次进入目标 `34 m` 范围时触发一次远距预告：线索标记轻呼吸、显示 `3.2 s` 的“前方有一处不自然的石面”，音频已就绪时从石块位置播放约 `360 ms` 的克制石质方向声；预告不显示准星、不计入观察进度。
- 目标投影进入以屏幕中心为圆心、短边 `9%` 为半径的区域，并连续稳定 `1.1 s` 后完成记录；超过短边 `14%` 视为偏离，保留 `0.35 s` 宽限后以每秒 `0.85 s` 的速度回退进度。
- 观察开始前使用 `120 ms` 对准防抖；冲刺、暂停、页面隐藏、场景离屏或入口预览期间不累积观察进度。
- 观察完成只记录本次会话，不能重复触发；本轮不阻挡瀑布完成、不写入本地或后端存档。
- 初始移动画质为 `low`；桌面初始为 `high`。自适应连续 `1.6 s` 超预算时下降一级，不在移动端自动升档。
- 页面不可见或游戏可见面积低于 `15%` 时暂停 RAF、音频与动态模拟；恢复可见后继续。
- WebGL 不可用、首帧生成失败或音频失败时分别显示可恢复错误；音频失败不阻塞探索。
- 加载界面必须等待世界构建、关键程序纹理与一次真实渲染完成后才消失，不使用固定超时伪装完成。
- 页面处于隐藏预载状态时不创建 WebGL；入口镜头结束且玩家未进入时停止 RAF，保留 GPU 资源但不持续模拟或渲染。

## 4. Controls

- 移动端左侧虚拟摇杆：`pointerdown` 捕获指针，拖动半径上限 `52 px`，`pointermove` 更新移动向量，`pointerup/cancel` 归零。
- 移动端柔性路径辅助只修正实际位移方向，镜头与右侧观察区保持完全由玩家控制；玩家明显横推摇杆时立即退出辅助。
- 移动端右侧观察区：单指拖动改变 yaw/pitch；只有从右侧非按钮区域开始的指针参与视角控制。
- 移动端跳跃：44×44 px 以上按钮使用 `onPointerDown`/`pointerdown`，落地时触发一次。
- 移动端冲刺：按住按钮开始冲刺，`pointerup/cancel/leave` 结束。
- 入口：真实场景准备完成后，点击“进入雨林”接管场景并解锁 AudioContext；加载期间按钮禁用，不能进入半成品世界。
- 桌面：进入后点击画布进入 Pointer Lock；鼠标观察，WASD 移动，Shift 冲刺，Space 跳跃。
- 通用：静音按钮使用点击切换；所有触控使用 Pointer Events，不同时绑定 mouse 与 touch 事件。
- 观察：不增加按钮；玩家使用现有右侧拖动或桌面鼠标把石块保持在画面中心，观察环以描边进度同步反馈。
- iOS：全局禁止长按 callout、文字选择和图片拖动；真实文本编辑控件恢复默认选择行为。

## 5. Win / Lose Conditions

- 胜利条件：首次抵达路径进度 `0.955` 或更远的位置。
- 完成界面：显示“瀑布已抵达”、本次探索时长、重新步行按钮与继续观察按钮。
- 第一处线索记录成功时显示“这些石头不是从山上滚下来的。”，但不暂停、不过早触发旅程结算。
- 体验没有失败、死亡、生命值或强制重开；碰撞和陡坡只阻止移动。
- 如果玩家离开道路，可通过暂停面板中的“回到小径”恢复到最近安全路径点。
- WebGL 或初始化失败属于技术错误状态，提供“重试”而不是失败结算。

## 6. Sound Effects

- 首次主动进入：点击入口时才解锁 AudioContext，并在后台 Worker 合成 60 个环境音缓冲；自动场景预览保持无声，失败时保持静音体验。
- 脚步：依据地表和步态触发程序化脚步，单次约 `80–240 ms`，音量随步速变化。
- 环境：风、昆虫、鸟声采用 8 个互质时长的循环层，循环长度约 `9.31–16.41 s`，避免明显共同周期。
- 水声：接近瀑布时按空间距离增加低频轰鸣、高频水帘与喷雾层。
- 跳跃/落地：起跳保持克制，落地按垂直速度触发短促低频冲击；弱落地不盖过环境音。
- 完成：抵达瀑布时不播放游戏化号角，使用 `1.2 s` 的环境音轻微抬升与水声展开作为完成反馈。
- 第一处观察完成：若 AudioContext 已准备好且未静音，播放约 `420 ms` 的低音石质共鸣，峰值不超过 master 的 `0.08`；声音失败不影响记录。
- 静音：立即暂停或衰减所有输出；恢复后不补播离线期间事件。
